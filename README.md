# 座席表作成アプリ (seat-arrange)

会場にテーブルと椅子を配置し、各椅子にメンバー（名前・XのID）を割り当てて座席表を作成できる、シンプルな Web アプリケーションです。

- 会場にテーブルを **0〜6個** 配置できます（ドラッグ＆ドロップで自由に移動可能）
- 各テーブルには椅子を **0〜8個** 配置できます
- 各椅子には **名前** と **X の ID** を持つメンバーを割り当てられます
- 作成したデータはブラウザの `localStorage` に自動保存され、再読み込みしても復元されます

サーバーやビルドツールは不要です。`index.html` をブラウザで開くだけで動作します。

## 使い方

1. `index.html` をブラウザ（Chrome / Firefox / Safari / Edge の最新版）で開きます。
2. 「＋ テーブルを追加」からテーブル名と初期の椅子数を指定してテーブルを作成します。
3. テーブル本体（円）をドラッグすると会場内の好きな位置に移動できます。
4. テーブル上部のツールバーから、テーブル名の変更（✎）・椅子の増減（－／＋）・テーブルの削除（✕）ができます。
5. 空いている椅子（＋）をクリックすると、メンバーの名前と X の ID を登録できます。登録済みの椅子をクリックすると編集・割り当て解除ができます。
6. ヘッダー右上の「会場をリセット」で、すべてのテーブル・椅子・メンバー情報を削除できます。

## テスト

コアロジック（`js/state.js`）の単体テストを Node.js で実行できます。

```sh
node test/logic.test.js
```

## ディレクトリ構成
